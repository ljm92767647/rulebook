# rule book for watching

한국어 초보자용 인터랙티브 교과서. 홈과 5종목을 독립적인 화면으로 제공합니다. 정적 HTML/CSS/JavaScript를 사용하여 설치 의존성을 없애고, 본문 데이터·SVG 그림·UI·상호작용을 분리했습니다.

## 실행

가장 간단한 방법은 `dist/index.html`을 브라우저로 여는 것입니다. 오프라인에서도 본문·그림·조작이 실행됩니다. 웹 폰트를 불러오지 못하면 시스템 글꼴을 사용합니다. 공식 출처 링크에는 인터넷이 필요합니다.

Node.js가 있다면 이 폴더에서 `npm start` 또는 `node serve.cjs` 실행 후 http://127.0.0.1:4173 에 접속하세요. 패키지 설치나 빌드가 필요 없습니다. 이미 같은 포트로 미리보기가 실행 중이면 기존 미리보기를 사용하거나 먼저 종료하세요.

`npm run check`는 문법, 데이터, 필수 목차, FAQ, 파일 참조를 확인합니다. 웹 호스팅에는 `dist/` 안의 파일을 그대로 올리면 됩니다. 주소는 `#/football`, `#/rugby`, `#/hockey`, `#/volleyball`, `#/polo`를 사용하므로 서버의 경로 재작성 설정이 필요 없습니다.

## 전체 소스 구조

```text
sport-school/
├── README.md
├── RULES-AND-VERIFICATION.md
├── package.json
├── serve.cjs
├── check.cjs
├── .gitignore
├── .openai/
│   └── hosting.json
└── dist/
    ├── index.html
    ├── favicon.svg
    ├── styles.css
    ├── app.js
    ├── components/
    │   ├── diagrams.js
    │   └── ui.js
    └── pages/
        ├── american-football.js
        ├── rugby.js
        ├── ice-hockey.js
        ├── volleyball.js
        └── polo.js
```

`pages/`에서 규칙, 역할, 출처, FAQ를 수정합니다. `components/ui.js`는 SportHeader·RuleCard·FlowDiagram·FAQ·SourceLinks에 해당하는 재사용 렌더러입니다. `diagrams.js`는 경기장·역할 배치·O/X·실습 그림을 만들고 `app.js`는 화면 이동과 상태를 관리합니다.

## 페이지 기능

| 화면 | 주요 학습·조작 |
|---|---|
| 홈 | 5종목 카드, 정확한 한 줄 소개, 읽는 순서 |
| 미식축구 | 다운 실습, 전진·손실·공격권 변경, 4th down 선택, 안전 득점, 펀트, NFL 2026 킥오프, 수비 포메이션 4종 |
| 럭비 | 태클→럭→공 나옴→수비 전진 4단계, 8 대 8 스크럼 3시점, 일반/럭/스크럼 오프사이드, 9번 특별 선, 미식축구 비교 |
| 아이스하키 | 오프사이드·아이싱 O/X, penalty 인원 실습, 5-on-4→5-on-3→추가 벌칙 대기, minor와 major 차이 |
| 배구 | 실제 시계 방향 로테이션, 서브 유지 득점, 정확한 전체 코트, 블록 접촉 제외, 전위/후위 제한, 기본/시험 위치 규정 |
| 폴로 | 진행선·ROW, 안전 접근/위험 crossing 토글, ride-off·hook O/X, 드리블 수비, 골 후 방향 변경 |

본문은 핵심 문장 1–2개와 그림 중심이며, 판정에 영향을 주는 예외만 펼침 설명으로 제공합니다. 반복 소개·안내·구간별 출처 문구를 삭제했습니다.

모든 종목에는 12개 필수 목차, 역할 클릭 설명, 공식 출처, 한 줄 핵심, 상황 흐름, FAQ가 있습니다. 총 FAQ는 37개입니다. 그림 확대, 키보드 포커스, 터치 버튼, 스크롤 목차, 반응형 화면을 제공합니다. 선수 원은 실제 신체 크기가 아닌 위치 아이콘입니다.

## 기준과 한계

NFL 2026, World Rugby 현재 온라인 Laws/Global Law Trials, NHL·IIHF 2026–27, FIVB 2025–2028와 2026 일부 대회 시험 규정을 기준으로 합니다. 폴로는 최신 통합본 자동 열람 제한 때문에 직접 확인 가능한 USPA 2024 기본 원문과 2025·2026 공식 개정문을 사용했습니다. 최신 폴로 통합본 전체 확인은 완료되지 않았으며 사이트 안에도 같은 한계를 표시했습니다. 상세 조항·출처·검토 결과는 `RULES-AND-VERIFICATION.md`를 보세요.
